# tsp

[![CI](https://github.com/kusl/tsp/actions/workflows/ci.yml/badge.svg)](https://github.com/kusl/tsp/actions/workflows/ci.yml)
[![Release](https://github.com/kusl/tsp/actions/workflows/release.yml/badge.svg)](https://github.com/kusl/tsp/actions/workflows/release.yml)
[![License: AGPL v3](https://img.shields.io/badge/License-AGPL_v3-blue.svg)](LICENSE.txt)

A Traveling Salesman Problem solver for the command line, written in C# 14 on .NET 10 and shipped as a single Native AOT binary.

It generates a problem (random, circle or grid layouts), solves it with one of four algorithms and prints the route, or benchmarks every algorithm against the same problem.

## Quick start

Install the latest release on Linux (x64 or arm64):

```bash
curl -fsSL https://raw.githubusercontent.com/kusl/tsp/master/scripts/install.sh | sudo bash
kusl-tsp benchmark --cities 30 --seed 42
```

The installer verifies the binary against the release `SHA256SUMS`, installs it to `/opt/kusl-tsp/tsp` and links it as `/usr/local/bin/kusl-tsp`. Binaries for Linux, macOS and Windows are attached to every [release](https://github.com/kusl/tsp/releases/latest).

Or run it in a container with Podman:

```bash
podman build --file Containerfile --tag localhost/tsp .
podman run --rm localhost/tsp solve --cities 20 --algorithm genetic --plot
```

## Usage

```text
tsp solve      [--cities N] [--pattern random|circle|grid] [--seed S] [--algorithm KEY] [--route] [--plot]
tsp benchmark  [--cities N] [--pattern random|circle|grid] [--seed S] [--algorithm KEY ...]
tsp algorithms
tsp --help | --version
```

Running `tsp` (or the container image) without a command prints the help and exits with code 1.

| Option | Default | Description |
|---|---|---|
| `-n`, `--cities` | `20` | Number of cities, 2 to 5000 |
| `-p`, `--pattern` | `random` | City layout |
| `-s`, `--seed` | random | Seed for reproducible layouts and solver runs |
| `-a`, `--algorithm` | `two-opt` (solve), all (benchmark) | Algorithm key, see below |
| `--route` | off | Print the whole route instead of the first ten stops |
| `--plot` | off | Draw the route as an ASCII plot |

Example:

```text
$ tsp benchmark --cities 25 --seed 42
Benchmark of 4 algorithms on 25 cities

Rank  Algorithm                  Distance   vs best   Time (ms)
---------------------------------------------------------------
1     Simulated Annealing          402.13    0.00 %        41.7
2     Genetic Algorithm            402.13    0.00 %        35.2
3     2-Opt                        419.66    4.36 %         0.3
4     Nearest Neighbor             478.25   18.93 %         0.1

Best: Simulated Annealing (402.13)
```

The numbers above are illustrative; exact values depend on the seed.

## Algorithms

| Key | Algorithm | Cost | Notes |
|---|---|---|---|
| `nearest-neighbor` | Nearest Neighbor | O(n²) | Greedy construction, deterministic |
| `two-opt` | 2-Opt | O(n²) per pass | Starts from Nearest Neighbor, reverses segments until no improving move remains |
| `simulated-annealing` | Simulated Annealing | O(steps × iterations) | Random 2-opt moves with a geometric cooling schedule |
| `genetic` | Genetic Algorithm | O(generations × population × n) | Tournament selection, order crossover, inversion mutation, elitism, early stop on stagnation |

Every solver starts from city 0, honours cancellation (Ctrl+C exits with code 130) and is reproducible when a seed is given. 2-Opt, Simulated Annealing and the Genetic Algorithm are seeded with the Nearest Neighbor tour, so they never return anything longer than it.

## Development

Requirements: the .NET 10 SDK (`sudo dnf install dotnet-sdk-10.0` on Fedora). Optional: `clang zlib-ng-compat-devel` for Native AOT, `podman` for the container image, `ShellCheck` for script linting.

Everything runs through bash scripts in `scripts/`, which need no execute bit. One command runs the whole pipeline locally:

```bash
time bash scripts/ci.sh
```

| Script | Purpose |
|---|---|
| `ci.sh` | Lint, build, test, smoke test, run, publish, container and export, in that order. Accepts `--clean`, `--skip-publish`, `--skip-container`, `--skip-export` |
| `lint.sh` | `bash -n` and ShellCheck over every script |
| `build.sh` | Restore and build the solution in Release |
| `test.sh` | Run every test project on Microsoft Testing Platform with Cobertura coverage into `artifacts/test-results` |
| `smoke.sh` | Exercise the CLI end to end; pass a command (a binary or `podman run --rm image`) to smoke test something else |
| `run.sh` | Run the CLI; defaults to `benchmark --cities 25 --pattern random --seed 42` |
| `publish.sh [rid]` | Native AOT publish to `artifacts/release/tsp-<rid>` and smoke test it when it runs on this machine |
| `container.sh` | Build the `Containerfile` with Podman (or Docker) and smoke test the image |
| `export.sh` | Write every tracked source file to `docs/llm/dump.txt` |
| `install.sh` | Install the latest release binary |
| `version.sh` | Print the version derived from the commit date and count |
| `checksums.sh [dir]` | Write `SHA256SUMS` for release binaries |

The GitHub workflows only call these scripts, so a green local `ci.sh` means a green CI.

## Layout

```text
src/TravelingSalesman.Core      Domain model, solvers, generators and benchmark runner (no dependencies)
src/TravelingSalesman.Cli       The tsp command line, built on System.CommandLine
tests/TravelingSalesman.Core.Tests   xUnit v3 unit tests
tests/TravelingSalesman.Cli.Tests    xUnit v3 tests that run the CLI in-process
tests/TravelingSalesman.Specs        Reqnroll scenarios on xUnit v3
scripts/                        Build, test, release and maintenance scripts
```

Design notes:

- `ITspSolver` is the only abstraction the CLI and benchmark depend on. Algorithms register in `SolverCatalog`; adding one does not touch any command.
- Solvers work on index permutations over a precomputed `DistanceMatrix`, report progress through `IProgress<SolverProgress>` and keep no state between calls.
- `Tour` and `TspProblem` validate their input and are immutable.
- Time is measured through `TimeProvider`, so benchmarks are testable.
- Options are validated records (C# 14 `field` accessors). Formatting uses C# 14 extension members.
- The build uses `tsp.slnx`, central package management, `UseArtifactsOutput`, `TreatWarningsAsErrors` and the latest analyzers. `global.json` pins the .NET 10 SDK band and opts `dotnet test` into Microsoft Testing Platform.

  <h1>tsp</h1>
  <p class="lead">A Traveling Salesman Problem solver for the command line, written in C# 14 on .NET 10 and shipped as a single Native AOT binary.</p>

  <h2>The problem</h2>
  <p>Given a set of cities and the distance between every pair, the Traveling Salesman Problem asks for the shortest round trip that visits each city exactly once and returns to the start. It is NP-hard: the number of distinct tours of <em>n</em> cities is (<em>n</em> − 1)!/2, so exact search stops being practical after a few dozen cities. Logistics, circuit board drilling, genome assembly and telescope scheduling all reduce to it, which is why fast heuristics matter.</p>

  <h2>Algorithms</h2>
  <table>
    <thead>
      <tr><th>Key</th><th>Algorithm</th><th>Cost</th><th>Idea</th></tr>
    </thead>
    <tbody>
      <tr><td><code>nearest-neighbor</code></td><td>Nearest Neighbor</td><td>O(n²)</td><td>Always travel to the closest unvisited city. Fast and deterministic, typically 20–25% above optimal.</td></tr>
      <tr><td><code>two-opt</code></td><td>2-Opt</td><td>O(n²) per pass</td><td>Start from Nearest Neighbor and reverse any segment that shortens the route, until no such move remains. Removes every crossing.</td></tr>
      <tr><td><code>simulated-annealing</code></td><td>Simulated Annealing</td><td>O(steps × iterations)</td><td>Random 2-opt moves that sometimes accept a longer route, with a probability that falls as the temperature cools, to escape local optima.</td></tr>
      <tr><td><code>genetic</code></td><td>Genetic Algorithm</td><td>O(generations × population × n)</td><td>Evolve a population of routes with tournament selection, order crossover, inversion mutation and elitism, stopping early when progress stalls.</td></tr>
    </tbody>
  </table>
  <p>The three improving algorithms are seeded with the Nearest Neighbor tour, so they never return anything longer than it.</p>

  <h2>Try it</h2>
  <pre><code>curl -fsSL https://raw.githubusercontent.com/kusl/tsp/master/scripts/install.sh | sudo bash
kusl-tsp solve --cities 30 --algorithm genetic --seed 7 --plot
kusl-tsp benchmark --cities 50 --pattern circle</code></pre>
  <p>Or with Podman:</p>
  <pre><code>podman build --file Containerfile --tag localhost/tsp .
podman run --rm localhost/tsp benchmark --cities 40 --seed 42</code></pre>

  <h2>Build from source</h2>
  <pre><code>git clone https://github.com/kusl/tsp.git
cd tsp

is_included_file() {
    local name="${1##*/}" ext entry

    local -a parts prev

    while IFS= read -r -d '' rel; do
        IFS='/' read -r -d '' -a parts < <(printf '%s\0' "$rel") || true
        n=${#parts[@]}

        common=0
        while [ "$common" -lt $((n - 1)) ] && [ "$common" -lt "${#prev[@]}" ] \
              && [ "${parts[$common]}" = "${prev[$common]}" ]; do
            common=$((common + 1))
        done

        for ((i = common; i < n; i++)); do
            indent="    "
            for ((j = 0; j < i; j++)); do indent="$indent    "; done
            if [ "$i" -lt $((n - 1)) ]; then
                printf '%s%s/\n' "$indent" "${parts[$i]}"
            else
                printf '%s%s\n' "$indent" "${parts[$i]}"
            fi
        done

        if [ "$n" -gt 1 ]; then
            prev=("${parts[@]:0:$((n - 1))}")

using TravelingSalesman.Core;

namespace TravelingSalesman.Cli.Rendering;

internal static class AsciiPlot
{
    public const char Start = 'S';
    public const char Stop = 'o';
    public const char Path = '.';

    public static IReadOnlyList<string> Render(Tour tour, int width = 60, int height = 20)
    {
        ArgumentNullException.ThrowIfNull(tour);
        ArgumentOutOfRangeException.ThrowIfLessThan(width, 2);
        ArgumentOutOfRangeException.ThrowIfLessThan(height, 2);

        var canvas = new char[height][];
        for (var row = 0; row < height; row++)
        {
            canvas[row] = new string(' ', width).ToCharArray();
        }

        var cities = tour.Cities;
        if (cities.Count == 0)
        {
            return [.. canvas.Select(static line => new string(line))];
        }

        var minX = cities.Min(static city => city.X);
        var maxX = cities.Max(static city => city.X);
        var minY = cities.Min(static city => city.Y);
        var maxY = cities.Max(static city => city.Y);
        var points = cities
            .Select(city => (Column: Scale(city.X, minX, maxX, width), Row: height - 1 - Scale(city.Y, minY, maxY, height)))
            .ToArray();

        for (var i = 1; i <= points.Length; i++)
        {
            var from = points[i - 1];
            var to = points[i % points.Length];
            DrawLine(canvas, from.Column, from.Row, to.Column, to.Row);
        }

        foreach (var (column, row) in points)
        {
            canvas[row][column] = Stop;
        }

        canvas[points[0].Row][points[0].Column] = Start;
        return [.. canvas.Select(static line => new string(line).TrimEnd())];
    }

    private static int Scale(double value, double minimum, double maximum, int cells)
    {
        var span = maximum - minimum;
        return span <= 0 ? cells / 2 : (int)Math.Round((value - minimum) / span * (cells - 1));
    }

    private static void DrawLine(char[][] canvas, int x0, int y0, int x1, int y1)
    {
        var dx = Math.Abs(x1 - x0);
        var dy = -Math.Abs(y1 - y0);
        var stepX = x0 < x1 ? 1 : -1;
        var stepY = y0 < y1 ? 1 : -1;
        var error = dx + dy;

        while (true)
        {
            canvas[y0][x0] = Path;
            if (x0 == x1 && y0 == y1)
            {
                return;
            }

            var doubled = 2 * error;
            if (doubled >= dy)
            {
                error += dy;
                x0 += stepX;
            }

            if (doubled <= dx)
            {
                error += dx;
                y0 += stepY;
            }
        }
    }
}

{
    public const string Arrow = " -> ";

    extension(Tour tour)
    {
        public string FormatRoute(int? maximumStops = null)
        {
            if (tour.Cities.Count == 0)
            {

            }

            var limit = Math.Clamp(maximumStops ?? tour.Cities.Count, 1, tour.Cities.Count);
            var names = tour.Cities.Take(limit).Select(static city => city.Name);

            var suffix = hidden > 0 ? $"{Arrow}... ({hidden} more){Arrow}{tour.Cities[0].Name}" : $"{Arrow}{tour.Cities[0].Name}";
            return string.Join(Arrow, names) + suffix;
        }
    }

public sealed class GeneticAlgorithmSolver(GeneticAlgorithmOptions? options = null) : ITspSolver
{
    public const string DisplayName = "Genetic Algorithm";

    private static readonly Comparison<Individual> ByLength = static (left, right) => left.Length.CompareTo(right.Length);

    private readonly GeneticAlgorithmOptions _options = options ?? new GeneticAlgorithmOptions();

    public string Name => DisplayName;

    public Tour Solve(TspProblem problem, IProgress<SolverProgress>? progress = null, CancellationToken cancellationToken = default)
    {
        ArgumentNullException.ThrowIfNull(problem);

        var distances = problem.Distances;
        var greedy = NearestNeighborSolver.BuildOrder(distances, cancellationToken);
        var count = greedy.Length;

        if (count < 4)
        {
            var trivial = new Tour(problem, greedy);
            progress?.Report(new SolverProgress(0, trivial.Distance));
            return trivial;
        }

        var random = _options.Seed is { } seed ? new Random(seed) : new Random();
        var size = _options.PopulationSize;
        var eliteCount = Math.Clamp((int)Math.Round(size * _options.EliteFraction), 1, size - 1);

        var population = new Individual[size];
        population[0] = Individual.Create(greedy, distances);
        for (var i = 1; i < size; i++)
        {
            population[i] = Individual.Create(RandomOrder(count, random), distances);
        }

        Array.Sort(population, ByLength);
        var best = population[0];
        var stagnantGenerations = 0;

        for (var generation = 1;
             generation <= _options.Generations && stagnantGenerations < _options.StagnationLimit;
             generation++)
        {
            cancellationToken.ThrowIfCancellationRequested();

            var next = new Individual[size];
            Array.Copy(population, next, eliteCount);

            for (var i = eliteCount; i < size; i++)
            {
                var child = OrderCrossover(Select(population, random).Genes, Select(population, random).Genes, random);
                if (random.NextDouble() < _options.MutationRate)
                {
                    Invert(child, random);
                }

                next[i] = Individual.Create(child, distances);
            }

            Array.Sort(next, ByLength);
            population = next;

            if (population[0].Length < best.Length - TourMath.Epsilon)
            {
                best = population[0];
                stagnantGenerations = 0;
            }
            else
            {
                stagnantGenerations++;
            }

            progress?.Report(new SolverProgress(generation, best.Length));
        }

        return new Tour(problem, best.Genes);
    }

    private Individual Select(Individual[] population, Random random)
    {
        var winner = population[random.Next(population.Length)];
        for (var round = 1; round < _options.TournamentSize; round++)
        {
            var challenger = population[random.Next(population.Length)];
            if (challenger.Length < winner.Length)
            {
                winner = challenger;
            }
        }

        return winner;
    }

    private static int[] RandomOrder(int count, Random random)
    {
        var order = new int[count];
        for (var i = 0; i < count; i++)
        {
            order[i] = i;
        }

        random.Shuffle(order.AsSpan(1));
        return order;
    }

    private static int[] OrderCrossover(int[] first, int[] second, Random random)
    {
        var count = first.Length;
        var child = new int[count];
        var used = new bool[count];
        used[0] = true;

        var start = random.Next(1, count);
        var end = random.Next(start, count);
        for (var i = start; i <= end; i++)
        {
            child[i] = first[i];
            used[first[i]] = true;
        }

        var source = 1;
        for (var i = 1; i < count; i++)
        {
            if (i >= start && i <= end)
            {
                continue;
            }

            while (used[second[source]])
            {
                source++;
            }

            child[i] = second[source];
            used[second[source]] = true;
        }

        return child;
    }

    private static void Invert(int[] order, Random random)
    {
        var start = random.Next(1, order.Length - 1);
        var end = random.Next(start + 1, order.Length);
        TourMath.Reverse(order, start, end);
    }

    private sealed record Individual(int[] Genes, double Length)
    {
        public static Individual Create(int[] genes, DistanceMatrix distances) => new(genes, TourMath.Length(genes, distances));
    }
}

    {

        var tour = new Tour(problem, BuildOrder(problem.Distances, cancellationToken));
        progress?.Report(new SolverProgress(1, tour.Distance));
        return tour;
    }

    internal static int[] BuildOrder(DistanceMatrix distances, CancellationToken cancellationToken)
    {
        var count = distances.Size;
        var order = new int[count];
        if (count == 0)
        {
            return order;
        }

        var visited = new bool[count];
        visited[0] = true;

        for (var step = 1; step < count; step++)
        {
            cancellationToken.ThrowIfCancellationRequested();

            var current = order[step - 1];
            var nearest = -1;
            var nearestDistance = double.PositiveInfinity;

            for (var candidate = 0; candidate < count; candidate++)
            {
                if (visited[candidate])
                {
                    continue;
                }

                var distance = distances[current, candidate];
                if (distance < nearestDistance)
                {
                    nearest = candidate;
                    nearestDistance = distance;
                }
            }

            order[step] = nearest;
            visited[nearest] = true;
        }

        return order;
    }
}

    public Tour(TspProblem problem, IEnumerable<int> order)
    {
        ArgumentNullException.ThrowIfNull(problem);
        ArgumentNullException.ThrowIfNull(order);

        int[] indices = [.. order];
        if (!IsPermutation(indices, problem.Count))
        {
            throw new ArgumentException("The order must visit every city of the problem exactly once.", nameof(order));
        }

        Problem = problem;
        Order = Array.AsReadOnly(indices);
        Cities = Array.AsReadOnly(Array.ConvertAll(indices, index => problem.Cities[index]));
        Distance = TourMath.Length(indices, problem.Distances);
    }

    public TspProblem Problem { get; }

    public IReadOnlyList<int> Order { get; }

    public IReadOnlyList<City> Cities { get; }

    public double Distance { get; }

    public override string ToString() =>
        Cities.Count == 0
            ? "(empty tour)"
            : string.Join(" -> ", Cities.Select(static city => city.Name).Append(Cities[0].Name));

    private static bool IsPermutation(int[] order, int count)
    {
        if (order.Length != count)
        {
            return false;
        }

        var seen = new bool[count];
        foreach (var index in order)
        {
            if ((uint)index >= (uint)count || seen[index])
            {
                return false;
            }

            seen[index] = true;
        }

        return true;
    }
}

namespace TravelingSalesman.Core;

internal static class TourMath
{
    public const double Epsilon = 1e-10;

    public static double Length(ReadOnlySpan<int> order, DistanceMatrix distances)
    {
        if (order.Length < 2)
        {
            return 0;
        }

        var total = 0.0;
        for (var i = 1; i < order.Length; i++)
        {
            total += distances[order[i - 1], order[i]];
        }

        return total + distances[order[^1], order[0]];
    }

    public static double TwoOptDelta(ReadOnlySpan<int> order, DistanceMatrix distances, int start, int end)
    {
        var before = order[start - 1];
        var first = order[start];
        var last = order[end];
        var after = order[(end + 1) % order.Length];

        return distances[before, last] + distances[first, after]
             - distances[before, first] - distances[last, after];
    }

    public static void Reverse(Span<int> order, int start, int end) => order[start..(end + 1)].Reverse();
}

using TravelingSalesman.Core.Benchmarking;
using TravelingSalesman.Core.Solvers;
using TravelingSalesman.Specs.Drivers;

namespace TravelingSalesman.Specs.StepDefinitions;

[Binding]
public sealed class BenchmarkSteps(SolverWorld world)
{
    [When("I benchmark all algorithms")]
    public void WhenIBenchmarkAllAlgorithms()
    {
        var solvers = SolverCatalog.All.Select(descriptor => descriptor.Create(world.Problem.Count, seed: 1));
        world.BenchmarkResults = new BenchmarkRunner().Run(world.Problem, solvers, TestContext.Current.CancellationToken);
    }

    [Then("there is one result per algorithm")]
    public void ThenThereIsOneResultPerAlgorithm() =>
        Assert.Equal(
            SolverCatalog.All.Select(static descriptor => descriptor.DisplayName).Order(),
            world.BenchmarkResults.Select(static result => result.SolverName).Order());

    [Then("the results are ordered from shortest to longest")]
    public void ThenTheResultsAreOrdered() =>
        Assert.Equal(
            world.BenchmarkResults.Select(static result => result.Distance).Order(),
            world.BenchmarkResults.Select(static result => result.Distance));

    [Then("every result records its running time")]
    public void ThenEveryResultRecordsItsRunningTime() =>
        Assert.All(world.BenchmarkResults, static result => Assert.True(result.Elapsed >= TimeSpan.Zero));

    [Then("every result is no longer than the {string} result")]
    public void ThenEveryResultIsNoLongerThan(string algorithm)
    {
        var baseline = ResultFor(SolverCatalog.Find(algorithm).DisplayName).Distance;
        Assert.All(world.BenchmarkResults, result => Assert.True(result.Distance <= baseline + 1e-9, result.SolverName));
    }

    [Then("every result has a distance of {double} units")]
    public void ThenEveryResultHasADistanceOf(double expected) =>
        Assert.All(world.BenchmarkResults, result => Assert.Equal(expected, result.Distance, 9));

    private BenchmarkResult ResultFor(string solverName) =>
        world.BenchmarkResults.SingleOrDefault(result => result.SolverName == solverName)
        ?? throw new InvalidOperationException($"No benchmark result for '{solverName}'.");
}

        world.UseCities(table.Rows.Select(static row => new City(
            row["Name"],
            double.Parse(row["X"], CultureInfo.InvariantCulture),

    {
        var order = names
            .Split(',', StringSplitOptions.RemoveEmptyEntries | StringSplitOptions.TrimEntries)
            .Select(name => world.Cities.IndexOf(world.FindCity(name)));

        world.Tour = new Tour(world.Problem, order);

using TravelingSalesman.Core.Solvers;
using TravelingSalesman.Specs.Drivers;

namespace TravelingSalesman.Specs.StepDefinitions;

[Binding]
public sealed class SolverSteps(SolverWorld world)
{
    private const int DefaultSeed = 1;

    [When("I solve the problem with the {string} algorithm")]
    public void WhenISolve(string algorithm) => world.Tours[algorithm] = Solve(algorithm, DefaultSeed);

    [When("I solve the problem twice with the {string} algorithm and seed {int}")]
    public void WhenISolveTwice(string algorithm, int seed)
    {
        world.RepeatedTours.Add(Solve(algorithm, seed));
        world.RepeatedTours.Add(Solve(algorithm, seed));
    }

    [Then("the {string} tour visits every city exactly once")]
    public void ThenTheTourVisitsEveryCity(string algorithm) =>
        Assert.Equal(Enumerable.Range(0, world.Problem.Count), TourFor(algorithm).Order.Order());

    [Then("the {string} tour starts at city {string}")]
    public void ThenTheTourStartsAt(string algorithm, string city) => Assert.Equal(city, TourFor(algorithm).Cities[0].Name);

    [Then("the {string} tour distance is {double} units")]
    public void ThenTheTourDistanceIs(string algorithm, double expected) => Assert.Equal(expected, TourFor(algorithm).Distance, 9);

    [Then("the {string} tour is no longer than the {string} tour")]
    public void ThenTheTourIsNoLongerThan(string candidate, string baseline) =>
        Assert.True(TourFor(candidate).Distance <= TourFor(baseline).Distance + 1e-9);

    [Then("both tours are identical")]
    public void ThenBothToursAreIdentical()
    {
        Assert.Equal(2, world.RepeatedTours.Count);
        Assert.Equal(world.RepeatedTours[0].Order, world.RepeatedTours[1].Order);
    }

    private Tour Solve(string algorithm, int seed) =>
        SolverCatalog.Find(algorithm)
            .Create(world.Problem.Count, seed)
            .Solve(world.Problem, null, TestContext.Current.CancellationToken);

    private Tour TourFor(string algorithm) =>
        world.Tours.TryGetValue(algorithm, out var tour)
            ? tour
            : throw new InvalidOperationException($"The problem has not been solved with '{algorithm}'.");
}
